## 📖 Visão Geral

O **AWS Student Builder Group – SENAI CIMATEC** é uma iniciativa estudantil oficial focada em computação em nuvem e tecnologias AWS, sediada na **Universidade SENAI CIMATEC** em Salvador, Bahia.

Este repositório contém o código-fonte da **plataforma web oficial do grupo**, atuando como o ponto de encontro digital da comunidade:
- 🌐 **Divulgação de Eventos**: Workshops, hackathons, palestras técnicas e grandes encontros (como o *AWS Community Day Nordeste*).
- 🚀 **Processos Seletivos**: Informações sobre recrutamento para novos membros, trainees e cargos de liderança.
- 📚 **Trilhas de Aprendizado**: Guia prático de evolução técnica e competências em Cloud & DevOps.
- 🤝 **Hub Comunitário**: Conexão com nossos canais do WhatsApp, Meetup, LinkedIn e Instagram.

---

## ✨ Destaques da Plataforma

- 🎨 **Design Moderno SaaS Dark-First**: Interface refinada inspirada em produtos digitais de ponta, com efeitos de glassmorphism, contrastes suaves e acentos temáticos AWS (`#FF9900`, `hsl(251, 100%, 65%)`).
- 🌐 **Suporte Bilíngue Nativo (i18n)**: Suporte dinâmico a Português (PT-BR) e Inglês (EN-US) com persistência local e seletor rápido no topo da página.
- ⚡ **Alta Performance & Tipografia**: Desenvolvido com React 18 e empacotado com Vite para carregamento quase instantâneo.
- 📱 **Responsividade Total**: Layout adaptável testado em smartphones, tablets e telas ultrawide.
- 🤹 **Micro-interações e Efeitos 3D**: Animações fluidas com Framer Motion, efeito 3D tilt nos cartões de valores e ScrollReveal progressivo.
- ♿ **Acessibilidade e SEO**: Estrutura semântica HTML5, meta tags Open Graph e componentes acessíveis via Radix UI.

## 🧭 Páginas e Recursos

A plataforma é modular e conta com rotas dedicadas para cada objetivo da comunidade:

| Rota | Página | Descrição & Recursos |
|:---|:---|:---|
| `/` | **Início (Home)** | Visão geral da iniciativa, métricas da comunidade, pilares de formação cloud, apresentação do Core Team executivo e banner de anúncios dinâmicos. |
| `/events` | **Eventos** | Calendário de atividades, eventos de destaque (ex: *AWS Community Day Nordeste*), histórico de workshops técnicos e integração direta com o Meetup. |
| `/join` | **Participe** | Portal de recrutamento completo: requisitos de admissão, matriz de competências (Trainee a Líder), detalhes dos 4 setores de atuação e link para inscrição via formulário. |
| `/about` | **Sobre Nós** | Missão institucional, cartões de valores interativos em perspectiva 3D, foto oficial da equipe e detalhes da relação com SENAI CIMATEC e Amazon Web Services. |
| `/links` | **Hub de Links** | Portal de acesso rápido estilo Linktree com cartões luminosos para a comunidade WhatsApp, Meetup, Instagram e LinkedIn. |
| `*` | **Página 404** | Tela de fallback estilizada para rotas inexistentes com atalhos de retorno para a Home. |

## 🛠️ Tecnologias e Arquitetura

O projeto utiliza uma stack moderna focada em produtividade, segurança de tipos e velocidade de renderização:

| Camada | Tecnologia | Descrição |
|:---|:---|:---|
| **Core & Framework** | [React 18](https://react.dev/) | Biblioteca base para construção de interfaces componentizadas |
| **Linguagem** | [TypeScript](https://www.typescriptlang.org/) | Tipagem estática rigorosa para robustez do código |
| **Bundler & Tooling** | [Vite](https://vitejs.dev/) | Ferramenta de build ultrarrápida com Hot Module Replacement (HMR) |
| **Estilização** | [Tailwind CSS](https://tailwindcss.com/) | Utilitários CSS customizados com paleta SaaS e tema dark nativo |
| **Componentes de UI** | [Radix UI](https://www.radix-ui.com/) / [shadcn/ui](https://ui.shadcn.com/) | Primitivos acessíveis, sem estilos opinativos e com suporte a teclado |
| **Animações** | [Framer Motion](https://www.framer.com/motion/) | Transições de rota, micro-interações e keyframes fluidos |
| **Roteamento** | [React Router DOM v6](https://reactrouter.com/) | Navegação SPA de cliente com controle de scroll e rotas dinâmicas |
| **Ícones** | [Lucide React](https://lucide.dev/) & [FontAwesome](https://fontawesome.com/) | Conjunto completo de ícones em vetor de alta resolução |
| **Gerenciamento de Estado** | [TanStack React Query](https://tanstack.com/query) | Cache e sincronização eficiente de dados |
| **Testes** | [Vitest](https://vitest.dev/) & [Testing Library](https://testing-library.com/) | Suíte de testes unitários e de componentes integrada |

## 💻 Como Executar Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) versão 18.0 ou superior
- Gerenciador de pacotes: `npm`, `yarn`, `pnpm` ou [Bun](https://bun.sh/)

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/MarcosMenezes30/aws-cloud-club-senai-cimatec-website.git
   cd aws-cloud-club-senai-cimatec-website
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   # ou com bun:
   bun install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   # ou:
   bun run dev
   ```

4. **Acesse no seu navegador:**
   ```text
   http://localhost:8080
   ```
   *(ou a porta indicada no terminal pelo Vite)*

### 🧪 Scripts Disponíveis

- `npm run dev`: Inicia o ambiente de desenvolvimento local.
- `npm run build`: Gera o pacote otimizado para produção na pasta `dist/`.
- `npm run preview`: Visualiza o build de produção localmente.
- `npm run lint`: Executa a verificação estática do código com ESLint.
- `npm run test`: Executa os testes unitários com Vitest.
- `npm run test:watch`: Executa os testes no modo observador.

## ☁️ Relação Institucional com a AWS e o SENAI CIMATEC

> O **AWS Student Builder Group – SENAI CIMATEC** é uma iniciativa estudantil autônoma, acadêmica e sem fins lucrativos mantida por alunos da Universidade SENAI CIMATEC.
>
> - As atividades seguem os padrões de aprendizado e certificação da **Amazon Web Services (AWS)**.
> - O grupo **não** atua como representante legal, empregador ou canal oficial de contratação da AWS.
