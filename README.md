# ☁️ AWS SBG Senai Cimatec GitHub Organization - Repositório Central (.github)

Bem-vindo(a) ao repositório `.github` da **AWS SBG Senai Cimatec GitHub Organization**. 

Este é um repositório especial utilizado pelo GitHub para armazenar os arquivos de saúde da comunidade (community health files), templates padrão e o perfil público da nossa organização. O objetivo principal aqui é centralizar a padronização e facilitar a manutenção dos nossos projetos, garantindo consistência em toda a organização.

</div>

---

## 🎯 Objetivo do Repositório

O repositório `.github` serve como a "fonte da verdade" (source of truth) para as diretrizes da nossa organização. Se um repositório individual não tiver o seu próprio arquivo de diretrizes (como um `CONTRIBUTING.md` ou templates de Issue), o GitHub utilizará automaticamente os arquivos padrões definidos aqui.

## 🚀 O que você encontra aqui (Funcionalidades)

*   **Perfil da Organização (`profile/README.md`):** O texto de apresentação e portfólio que aparece na página inicial da nossa organização no GitHub.
*   **Templates de Issues:** Modelos padronizados (na pasta `.github/ISSUE_TEMPLATE/`) para garantir que os relatos de bugs e solicitações de novas funcionalidades contenham todas as informações necessárias para os desenvolvedores.
*   **Template de Pull Request (`PULL_REQUEST_TEMPLATE.md`):** Um checklist padrão e estrutura de descrição para envios de código.
*   **Código de Conduta (`CODE_OF_CONDUCT.md`):** Nossas regras e expectativas para garantir um ambiente acolhedor, seguro e inclusivo para todos os contribuidores.
*   **Guia de Contribuição (`CONTRIBUTING.md`):** Instruções passo a passo sobre fluxos de trabalho e como a comunidade pode contribuir de forma eficaz com nossos projetos.
*   **Política de Segurança (`SECURITY.md`):** Instruções detalhadas sobre como relatar vulnerabilidades de segurança de forma responsável e confidencial.

## ⚙️ Como Funciona (Herança de Arquivos)

Os arquivos contidos na raiz deste repositório ou dentro de sua pasta `.github/` são herdados automaticamente por todos os outros repositórios públicos e privados desta organização. 

**Exceção:** Se um projeto específico precisar de um template ou guia diferente, basta criar o arquivo correspondente diretamente naquele repositório. O arquivo local sempre irá sobrescrever (override) o padrão da organização definido aqui.
